# Workshop materials

These resources support the Copilot Universe Admin Policies workshop. Use the long-form guide for the full session content and the cheat sheet as a concise reference during the hands-on scenarios.

- [Long-form workshop guide](LongVersion-FinalVersion.pdf)
- [Workshop cheat sheet](CheatSheet-FinalVersion.pdf)

The workshop uses three stakeholder scenarios—leadership, finance, and security—to practice assessing Copilot adoption, understanding organizational spend and ownership, and reviewing policies, access, and administrative controls. Participants finish by identifying actions to take back to their organization.
